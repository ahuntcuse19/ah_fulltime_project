# Seed as SQL

Generated by `npm run seed:sql` from the same data and engine as `npm run seed`.
Apply the files in numeric order in the Supabase SQL editor (or any SQL client) when
the seed script cannot reach the database directly. Ids are computed in Postgres with
`uuid_generate_v5` over the same namespace and natural keys as `src/lib/ids.ts`, so the
resulting rows are identical to a `npm run seed` run. File 01 truncates every table.
